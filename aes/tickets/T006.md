# T006 — Client Authentication & Session Management

## Context

T005 established the project scaffold with Config parser, Repository layer, and Slim routing. T006 implements client authentication — the gateway to all client-area features.

## Acceptance Criteria

- [ ] AC1 — Login form at `/clientarea.php` (GET)
- [ ] AC2 — Login processor at `/dologin.php` (POST) — validates credentials
- [ ] AC3 — WHMCS 5.3.9 password hashing compatibility: `md5($password . $salt)` where salt = first 2 chars of stored hash
- [ ] AC4 — Session management: PHP sessions with secure cookies
- [ ] AC5 — Remember me functionality (long-lived token)
- [ ] AC6 — Password reset flow: `/pwreset.php` (GET/POST)
- [ ] AC7 — Logout at `/logout.php` — destroys session
- [ ] AC8 — Auth middleware for protected routes
- [ ] AC9 — Unit tests for password verification
- [ ] AC10 — Integration test against live service login (Playwright)

## Scope

**In scope:**
- Client login/logout
- Password verification (WHMCS 5.3.9 compatible)
- Session handling
- Password reset email (stub — no actual email sending yet)
- Auth middleware

**Out of scope:**
- Admin authentication (T012)
- Two-factor authentication (not in live service)
- OAuth/SSO (not in live service)

## Dependencies

- `src/Repository/ClientRepositoryInterface` — findByEmail, verifyPassword
- `src/Config.php` — reads `configuration.php`
- Live `configuration.php` for DB credentials
