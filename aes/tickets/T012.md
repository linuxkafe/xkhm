# T012 — Admin Panel (Core CRUD)

## Context

T011 completed affiliates. T012 implements the admin panel — client management, invoice administration, and basic CRUD operations.

## Feature Map from Live Service

| Page | Features | DB Tables |
|------|----------|-----------|
| `admin/clientdetails.php` | View/edit client | `tblclients` |
| `admin/invoices.php` | Invoice management | `tblinvoices`, `tblinvoiceitems` |
| `admin/orders.php` | Order management | `tblorders` |
| `admin/clients.php` | Client listing | `tblclients` |

## Acceptance Criteria

- [ ] AC1 — Admin login (separate from client login)
- [ ] AC2 — Client listing and search
- [ ] AC3 — Client detail view/edit
- [ ] AC4 — Invoice listing with status filter
- [ ] AC5 — Basic admin navigation
- [ ] AC6 — Tests for admin auth

## Scope

**In scope:**
- Admin authentication (separate from client)
- Client listing and search
- Client detail view
- Basic admin dashboard

**Out of scope:**
- Full admin panel (deferred to T019)
- Advanced reporting
- Billing automation

## Dependencies

- `tbladmins` — admin accounts (separate from tblclients)
- Existing repository layer for data access
- Admin middleware for route protection
