## Context

T001 established the live service profile (19 public pages, 3 active gateways). T002 established the database schema. T003 will deep-dive into each feature area to understand exactly what the live service does, page by page.

- [ ] AC1 — Client area: all sub-features enumerated (products, addons, domains, tickets, invoices, affiliates, contact info, security)
- [ ] AC2 — Billing: invoice generation, payment processing, credit notes, billable items
- [ ] AC3 — Domains: checker, registration, renewal, DNS management, WHOIS
- [ ] AC4 — Support tickets: submission, viewing, replies, departments, categories
- [ ] AC5 — Affiliates: registration, tracking, commissions, withdrawal
- [ ] AC6 — Knowledgebase: categories, articles, search, comments
- [ ] AC7 — Each feature mapped to corresponding DB tables
- [ ] AC8 — API endpoints documented (WHMCS API v1)
