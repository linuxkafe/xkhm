# T020 — Flutter Client Application (Web + Mobile)

## Context

The xkhm service is currently a server-rendered PHP/Slim 4 application. The operator
requires a Flutter application reusing the LINUXKAFE design language already present at
`http://www.linuxkafe.com`, with the same colour scheme, in Portuguese (Brazil), talking
to the **existing** PHP backend (no new database, no schema changes).

The PHP backend stays authoritative. Flutter is a **new front-end** consuming the same
data through an HTTP API, so the live WHMCS database (`linuxkonect`) remains the single
source of truth.

## Scope

### In scope
- Flutter project scaffold at `flutter/xkhm_app/` (web + Android + iOS targets)
- Design system ported 1:1 from `www.linuxkafe.com` CSS custom properties
- Screens: Login, Home, Client Area (dashboard), Invoices, Domains, Tickets,
  Knowledgebase, Announcements, Domain Checker, Server Status
- API client layer consuming the existing PHP endpoints
- State management (provider pattern) + session persistence
- Playwright E2E suite running against the Flutter **web** build

### Out of scope
- Any change to the WHMCS schema or to `configuration.php`
- Replacing the PHP backend
- Admin panel in Flutter (separate future ticket)
- Payment gateway UI (read-only invoice display only)
