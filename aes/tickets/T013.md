# T013 — Payment Gateway Integrations

## Context

T012 completed admin auth. T013 implements real payment gateway integrations — PayPal, Authorize.Net, WorldPay.

## Feature Map from Live Service

| Gateway | Page | Integration |
|---------|------|-------------|
| PayPal | `paypal.php` | IPN (Instant Payment Notification) |
| Authorize.Net | `authorizenet.php` | AIM (Advanced Integration Method) |
| WorldPay | `worldpay.php` | JS/Hosted Payment Page |

## Acceptance Criteria

- [ ] AC1 — PayPal IPN handler
- [ ] AC2 — Authorize.Net SIM/AIM processor
- [ ] AC3 — WorldPay hosted page handler
- [ ] AC4 — Gateway configuration storage
- [ ] AC5 — Test mode support
- [ ] AC6 — Gateway-specific callback handling

## Scope

**In scope:**
- PayPal IPN verification and payment processing
- Authorize.Net AIM transaction processing
- WorldPay hosted page redirect handling
- Gateway configuration (API keys, test mode)
- Webhook/callback handlers for each gateway

**Out of scope:**
- Cryptocurrency payments
- Bank transfer/manual payment
- Subscription billing automation

## Dependencies

- `tblaccounts`: Payment account balances
- `tblinvoiceitems`: Line items for payment allocation
- Live gateway API credentials (sandbox initially)
