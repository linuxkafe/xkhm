# T034 — O painel de administração (as funções que faltam)

## Contexto

O `/admin` responde `200` e mostra:

```html
<h1>Admin Panel</h1>
<p><a href="/admin/logout.php">Terminar sessão</a></p>
```

Nenhuma das funções do WHMCS. O operador tem, na prática, um painel
vazio.

### A causa: um ticket fechado com critérios por cumprir

O **T012** ("Admin Panel — Core CRUD") foi marcado `done` no kanban. O
seu próprio ficheiro diz `status: pending`, e o `T012-learn.md` diz, sem
ambiguidade:

> Implemented the **admin authentication layer** — admin login, session
> management, and route protection.

Dos seis critérios de aceitação do T012:

| AC | Critério | Estado real |
|----|----------|-------------|
| AC1 | Login de administrador | ✅ |
| AC2 | Listagem de clientes com pesquisa | ❌ |
| AC3 | Detalhe do cliente | ❌ |
| AC4 | Listagem de faturas com filtro | ❌ |
| AC5 | Navegação do painel | ❌ |
| AC6 | Testes da autenticação | ✅ |

Três de seis nunca foram cumpridos, e **não houve `T012-verify.md`** —
a fase de verificação, que é a que apanha precisamente isto, não correu.
O kanban ficou `done` na mesma.

**Isto é a lição de T034, e vale mais do que o painel.**

## Scope

### In scope

**As páginas**
| Rota | O quê |
|------|-------|
| `/admin` | **Dashboard** — contagens, receita, tickets abertos, actividade recente |
| `/admin/clients.php` | Lista, pesquisa, paginação |
| `/admin/clients.php?id=N` | Detalhe: dados, faturas, pedidos, domínios, tickets, transações |
| `/admin/invoices.php` | Lista, filtro por estado, pesquisa, paginação |
| `/admin/invoices.php?id=N` | Detalhe com os itens e o total |
| `/admin/orders.php` | Lista e detalhe |
| `/admin/tickets.php` | Lista, filtro por estado |
| `/admin/tickets.php?id=N` | Detalhe com as respostas, e **responder** |
| `/admin/domains.php` | Lista |
| `/admin/affiliates.php` | Lista |
| `/admin/search.php` | Pesquisa global (clientes, faturas, tickets, domínios, pedidos) |
| `/admin/config.php` | Configuração (leitura) |

**A infra-estrutura**
- `AdminLayout` — a casca do painel (navegação lateral, conteúdo), com
  os mesmos tokens: **dark mode** e **mobile**
- `AdminRepository` — as consultas de leitura do painel
- Controladores por área
- CSS do painel, em `whmcs.css` (com o modo escuro e o telemóvel)

**As operações**
- **Responder a um ticket** (escrita, via `TicketService`)
- **Dar crédito a um cliente** (escrita, via `CreditService`)

### Out of scope

- As 110 páginas do WHMCS. Isto é o **núcleo operacional**, não uma
  cópia.
- Criar/editar produtos, preços, gateways (o `config.php` é de leitura)
- Relatórios avançados, facturação automática, campanhas de e-mail
- O painel em Flutter (decisão do T025, revista só se o PHP não der
  conta)
- A auditoria (`tblactivitylog`) — escrever nela é um trabalho à parte
