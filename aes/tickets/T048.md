# T048 — O tipo de interligação do servidor

## Contexto

O operador: «ao criar o novo servidor não é indicado que tipo de
interligação/plugin para o configurar».

O `tblservers` tem uma coluna `type` — e é a mais importante de
todas: é o **módulo** que aprovisiona e configura o servidor. Na
instalação:

```
LINUXKAFE   →  virtualmin
WordPress   →  whmcs_multisite
```

E o formulário do painel **não a mostrava**, e o repositório
**não a gravava** — um servidor novo ficava sem tipo, e sem tipo
não há aprovisionamento.

É a página `configservers` do WHMCS: o campo «Type» é um menu com
os **módulos de servidor** (os plugins de `modules/servers/`: cPanel,
Plesk, DirectAdmin, Virtualmin, WHMCS MultiSite, …).

## O que se propõe

1. A lista dos **módulos de servidor** do WHMCS, extraída da
   instalação original (`modules/servers/`) — 38 identificadores.
2. O formulário do servidor com o **tipo**, e a explicação do que
   ele é.
3. O repositório a **gravar** o tipo (hoje não o grava).

## Acceptance criteria

- [x] AC1 — O formulário indica o **tipo** (o módulo) e explica-o
- [x] AC2 — A lista traz os módulos do WHMCS, incluindo os dois em
      uso (`virtualmin`, `whmcs_multisite`)
- [x] AC3 — O tipo é **gravado** e volta a ser lido
- [x] AC4 — Um servidor novo sem tipo é recusado (o tipo é
      obrigatório: sem ele não há aprovisionamento)
- [x] AC5 — Todos os portões verdes
