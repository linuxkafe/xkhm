# T049 — A interface de 2026, ao estilo do design system

## Contexto

O operador: «o tipo de letra continua a não ser o moderno, o logotipo
se estiver num fundo escuro tem de ter um fundo branco em vez de
apresentar a cor invertida, verifica se consegues modernizar mais o
interface, mais ao estilo do design system, mas sem referências da
UP, e mantendo o esquema de cores».

Três coisas, e uma delas é um **defeito de acessibilidade**.

### O tipo de letra

As fontes já são servidas (T047) — o painel usa a Inter, a app
também. Mas o que se vê não é o que o design system pede:

| | O que há | O que o sistema pede |
|---|---|---|
| Corpo | Inter 14px/1.5 ✓ | 14px/1.5 ✓ |
| Títulos | **Poppins** 500, 28/22/18px | **uma** família, 600, 24/20/16px |

OPoppins é uma face geométrica de 2016 — é exactamente o «tipo de
letra de 2014» que o operador reconhece. E o design system nomeia
**uma** família: `Inter, -apple-system, …`.

### O contraste dos títulos — um defeito

`h1, h2, h3, h4` são `var(--color-primary)` — o **amarelo** sobre
branco. O contraste do `#fbb202` sobre `#ffffff` é de **1.9:1**, e
o WCGA exige 4.5:1 (3:1 para texto grande). Um título amarelo sobre
branco **não se lê**.

O design system diz «high contrast text» e «use the palette, not
arbitrary colors» — a paleta tem o amarelo, mas o amarelo é o
**acento**, não o texto.

### O logotipo

O operador: num fundo escuro, o logotipo deve ter **fundo branco**,
e não a cor invertida. É uma decisão melhor do que a minha: a marca
fica **fiel** (o wordmark preto é o wordmark preto) e o fundo
branco é a placa.

## O que se propõe

O **design system's forma**, mantendo o **esquema de cores** do
LINUXKAFE:

1. **A tipografia** — Inter em todo o lado (uma família), a escala do
   sistema (24/600, 20/600, 14/400, 12/400), e o mono para os
   números e os identificadores.
2. **O contraste** — os títulos passam à cor do texto; o amarelo
   fica como acento (o item activo, o botão primário, o anel de
   foco).
3. **Os componentes** — as tabelas com divisores subtis (e não uma
   grelha), os botões sem a inversão de cor no *hover*, os cartões
   com borda (e não com sombra pesada), os campos com o anel de
   foco, os avisos com a borda.
4. **O logotipo** — a variante original, sobre uma placa branca.
5. **A app** — a mesma escala e os mesmos componentes.

## Acceptance criteria

- [x] AC1 — Uma **única** família tipográfica (a do design system)
- [x] AC2 — A escala é a do design system
- [x] AC3 — Os títulos têm **contraste suficiente** (o do texto, e
      não o amarelo)
- [x] AC4 — Os componentes seguem o sistema: bordas em vez de
      sombras, divisores subtis, *hover* sem inversão
- [x] AC5 — O logotipo vai **sobre fundo branco**, e a marca fica
      fiel
- [x] AC6 — O esquema de cores **não muda**
- [x] AC7 — Todos os portões verdes
