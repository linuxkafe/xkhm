# T036 — A interface mobile, modernizada

## Contexto

O operador: «podemos melhorar o interface para mobile com um interface
mais modernizado».

O pedido é vago, e a tentação é vaga-lo. O que **não** é vago é a
captura: a aplicação num telefone de 390 px mostrava isto.

```
┌─────────────────────────────┐
│ LINUXKAFÉ    Início      ⇥  │  a barra
├─────────────────────────────┤
│ Bemvindo                    │  ← um cartão escuro, 300 px de altura
│ Xkhm Teste                  │     só para dizer o nome
│ xkhm-test@example.com       │
│                             │
│ ┌─────────────────────────┐ │
│ │ ▣ $ 0.00                │ │  ← um cartão só para um número
│ │   Crédito disponível    │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ ▣ $ 149.90              │ │  ← empilhado, porque não cabem
│ │   Total em aberto       │ │     dois lado a lado
│ └─────────────────────────┘ │
│                             │
│ Notícias                    │
│ ┌─────────────────────────┐ │
│ │ Intervenção entre as... │ │  ← o corpo inteiro, 15 linhas
│ │ Hoje, dia 23 de Janeiro │ │
│ │ de 2018 das 22:30 ...   │ │
│ │ ...                      │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

O ecrã de início, num telefone, tem **um número e meio** de informação
visível. E o cliente tem de rolar muito para chegar a qualquer coisa.

## Reconhecimento

| Facto | Evidência |
|-------|-----------|
| Os `LkStatTile` têm **220 px fixos** | `home_screen.dart` — num telefone de 390 px (342 úteis) não cabem dois, por isso empilham |
| O cartão de saudação come a primeira dobra do ecrã | captura a 390×844 |
| As notícias mostram o **corpo inteiro** | o `LkHtml` renderiza tudo |
| A barra de navegação é a do Material 2 | `BottomNavigationBar` |
| Não há **pull-to-refresh** em lado nenhum | `grep RefreshIndicator` → nada |
| Os alvos já são ≥44 px e não há scroll horizontal | os testes de T023 verificam-no |
| O dark mode já funciona | idem |

## Scope

### In scope

**O ecrã de início**
- A saudação passa a ser um **herói** moderno: o nome, o email, e as
  duas figuras — sem um cartão gigante
- As figuras ficam **lado a lado** num telefone, com o tamanho certo

**As listas e os cartões**
- As notícias e os artigos **resumem-se** a três linhas, com um
  «ler mais» que expande
- **Pull-to-refresh** nos ecrãs que carregam dados

**A navegação**
- A barra de baixo passa a ter o **indicador** moderno (Material 3)

### Out of scope

- Uma redesenho completo da aplicação
- Animações de transição entre ecrãs
- O modo escuro (já funciona — não se mexe)
- As tabelas do painel (que é PHP, e é outra coisa)

## Acceptance Criteria

- [ ] AC1 — As figuras ficam lado a lado num telefone de 390 px
- [ ] AC2 — A saudação é um herói compacto
- [ ] AC3 — As notícias resumem-se, com «ler mais»
- [ ] AC4 — A barra de navegação tem indicador
- [ ] AC5 — Os ecrãs de dados têm pull-to-refresh
- [ ] AC6 — Sem scroll horizontal, alvos ≥44 px, dark mode intacto
- [ ] AC7 — Todos os portões verdes
